# Desktop icons

The `originals/` folder contains publisher artwork. Windows Terminal offers multiple release channels and high-contrast variants. PowerToys uses its upstream PNG utility artwork, and the separate `archive/` folder marks its older SVG. GNOME and KDE icons come from the individual application's own repository when available. KDE Okular's upstream SVGZ is supplied as decompressed SVG. KDE Konsole and Gwenview use upstream PNGs.

The `themes/` folder contains alternate artwork from Ubuntu Yaru, KDE Breeze, Papirus, elementary and WhiteSur. Keep theme marks distinct from the official app icons.

`desktop-sources.json` records the pinned source revision, exact upstream filename, original Git blob ID and installed SHA-256 for each file. Asset-specific terms apply. Windows Terminal artwork uses CC BY-ND 4.0, so use copies with attribution as supplied. PNG and ICO files are retained in their original formats.
