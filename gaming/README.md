# Gaming assets

Includes 396 assets, 393 SVG files and 3 PNG fallbacks.
The asset manifest records upstream file links, content hashes, authors and license terms per asset.

| Folder | Contents |
| --- | --- |
| `ui/outline` and `ui/filled` | Original Tabler gaming controls, tabletop symbols and heads-up display icons. |
| `illustrations` | Game Icons controls, inventory, loot, achievements and tabletop illustrations, with labeled transparent versions. |
| `titles/open-source` | 7 original game or game-platform marks. |
| `platforms/launchers` | 4 original launcher marks, including alternate artwork. |
| `licenses` | Upstream notices for included sets and individual project marks. |

For Game Icons illustrations, credit the creator named in the manifest and link to [Game-icons.net](https://game-icons.net/about.html).
The transparent versions remove the black background path and keep the original white art.

## PC games and platforms

`gaming-catalog.tsv` includes 105 title and platform entries. It lists 41 existing file-name matches, 3 newly included platform entries, and 61 publisher references.
The catalog includes established PC titles, recent popular Steam titles, major publisher titles and gaming infrastructure.
Existing entries point to the current catalog paths. A publisher reference identifies the game and its branded source.
